## Реальный публичный TikTok

- Публичный поиск `фильм`: страница не отдала metadata/search JSON.
- Хэштег `#фильм`: страница не отдала metadata/search JSON.
- Metadata публичного видео `7288826284572937515`: HTTP 200, настоящая дата публикации, 42 300 000 просмотров, CDN URL.
- MP4 этого видео: 2 404 292 байта, скачан из публичного CDN во временный каталог, затем удалён.

Видео старое, используется только для диагностики; в рабочую подборку не добавлено. Наличие настоящих metadata и MP4 подтверждает работу резервного provider по публичным URL. Автоматическое обнаружение свежих неизвестных видео на проверенном подключении остаётся ограничено TikTok. Seed fallback требует свежих ссылок от пользователя; это явно указано в README.
