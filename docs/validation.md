## Реальный публичный TikTok

- Публичный поиск `фильм`: страница не отдала metadata/search JSON.
- Хэштег `#фильм`: страница не отдала metadata/search JSON.
- Metadata публичного видео `7288826284572937515`: HTTP 200, настоящая дата публикации, 42 300 000 просмотров, CDN URL.
- MP4 этого видео: 2 404 292 байта, скачан из публичного CDN во временный каталог, затем удалён.

Видео старое, используется только для диагностики; в рабочую подборку не добавлено. Наличие настоящих metadata и MP4 подтверждает работу резервного provider по публичным URL.

## Повторная проверка и исправление 0.1.1

Первоначальный вывод о недоступности всего поиска был связан с ошибкой provider: новая сессия открывала поиск напрямую и ждала только 2,5 секунды. Исправлено обычное посещение главной страницы и ожидание настоящего ответа поиска, с сохранением остановки при CAPTCHA и ограничений timeout.

- `фильм`: получены настоящие результаты, HTTP search JSON со status_code=0 и 12 видео, без авторизации.
- `момент из фильма`: 11 настоящих результатов. Самый свежий имел возраст около 28 часов; eligible_count=0 по строгому фильтру 24 часа. Счётчики и публикация не подменялись.
- `#фильм`: результаты всё ещё недоступны. Частичная доступность теперь отображается отдельно от полного отказа поиска.
- Добавлены regression tests: задержанный ответ после служебного JSON, обычная инициализация публичной сессии, прекращение навигации при CAPTCHA на главной странице, частичное здоровье поиска.

Поиск по словам работает на проверенном подключении; полнота и наличие свежих кандидатов не гарантируются анонимной выдачей. Seed URLs остаются необязательным дополнительным источником.
