Проверено 02.10.2026 локально на Windows, Python 3.13.5, в отдельной `.venv`.

Тесты охватывают фильтры, рост, ranking, доставку и дедупликацию, паузу/остановку, авторизацию, динамические запросы, SQLite, расписание и retention. Для автоматического поиска проверены ожидание реального ответа после служебного JSON, нормальная инициализация браузерной сессии, остановка при CAPTCHA, повтор на следующем цикле, продолжение после ошибки отдельного запроса, поиск хэштегов через обычную поисковую страницу и доступная пустая выдача. Старые результаты не вытесняют свежие из лимита кандидатов. Сообщения об отказе поиска отличаются от отсутствия подходящих видео.

## Реальный автоматический поиск

Ручные ссылки не использовались. Ни токен Telegram, ни TikTok-аккаунт для проверки не требовались.

- Поиск `нарезка из фильма` нашёл видео `7691731925597293831` с реальной датой публикации, возрастом 19,47 часа и 21 100 просмотрами. `eligible_count=1` по настроенным фильтрам возраста, просмотров, тематики и языка. Наличие русского языка оценивается эвристикой по описанию, хэштегам и доступным субтитрам, а не проверкой аудио.
- Запрос `#фильм` через `/search?q=…` вернул настоящие metadata. Проверенные результаты старше 24 часов и в подборку не входят.
- При последовательной проверке десяти запросов получены 104 уникальных видео; один прошёл фильтры. Последующий переход на страницу `/tag/…` потребовал CAPTCHA. Такие страницы удалены из рабочего поиска: хэштеги передаются в обычный поисковый запрос.
- Попытка получить дополнительные результаты через вкладку «Видео» и публичные профили не дала подтверждённого источника свежих публикаций; встречалась CAPTCHA. Эти варианты в программу не добавлены, проверки не обходились.

Ранее публичные metadata диагностического видео `7288826284572937515` и MP4 размером 2 404 292 байта были проверены через обычные страницы/CDN. Старое видео не добавлялось в рабочую подборку.

## Практические ограничения

Автоматический поиск подтверждён на реальных данных, но полнота и постоянная доступность анонимной выдачи не гарантируются. TikTok часто выдаёт старые популярные видео и может ограничивать доступ. При отказе бот сообщает проблему источника и сам повторяет поиск на следующем цикле; ручного резерва нет. Получение трёх подходящих свежих роликов на каждом цикле не заявляется проверенным.

Доступ к VPS отсутствует. Реальная отправка Telegram и apt/systemd локально не выполнялись; проверены mocked Bot API, команды, offline smoke и синтаксис установщика. Пользователь сообщил об успешной авторизации и запуске сервиса на VPS. GitHub Actions настроен на Python 3.12/Ubuntu 24.04; результат удалённого CI в этой сессии не проверен. OCR и необязательный TMDB покрыты локальными тестами; live TMDB key не предоставлен.
